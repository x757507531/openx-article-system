# 改稿

初稿写完再读这一份。顺序按重要性排，前四条不过关就不用看后面的。

## 十二条检查表

### 1. 段落节奏（最容易跑偏）

按空行切开，数每段的中文字数。

- 中位数应当落在 15 到 30 字之间。
- 连续三段都超过 60 字 → 违规，回去拆。
- 一段里有三句以上完整句 → 拆成三段。

**修法**：把长段里的转折点找出来，每个转折另起一段。不要靠加逗号救，靠换行救。

原句：

> 我后来复盘发现，真正让我加速的是几次跟大号的互动，不是刻意蹭，是真的在评论区聊出了有价值的内容，被对方注意到，被转发，被 QT，这条评论本身的曝光量比我自己发的推还高。

改成：

> 我后来复盘发现，真正让我加速的是几次跟大号的互动。
>
> 不是刻意蹭，是真的在评论区聊出了有价值的内容，被对方注意到，被转发，被 QT。
>
> 有一次我在一个万粉博主的推文下面写了一段认真的分析，大概三四百字，那条评论本身的曝光量比我自己发的推还高。

### 2. 「我」和「你」在不在

全文搜「我」和「你」。

- 通篇没有第一人称动作 → 这是说明书，重写。
- 只有「我」没有「你」→ 变成自述，加读者视角。
- 只有「你」没有「我」→ 变成培训教材，加自己的经历。

语料值供参考：每万字「你」88 次、「我」81 次。差得太远说明位置站错了。

### 3. 数字锚点和自撞细节

- 全文没有一个可核对的数字 → 补。补不出来说明材料不够，缩短篇幅。
- 全文没有一处作者自己撞出来的细节（报错、耗时、被坑、看错）→ 补。这一项没法靠查资料补，只能来自使用者本人，问用户。

### 4. 泼冷水段在不在

提到任何工具、产品、方法、方案，往下找有没有讲它边界的段落。

没有 → 加一段。写法：这个东西慢在哪、不适合谁、我这个结论有什么前提、有多少是运气和窗口期。

软广稿没有这一段，直接退回重写。

### 5. 机构腔清理

搜这些词，命中即删：

赋能、抓手、闭环、商业闭环、拉通、对齐（人际语境除外）、降本增效、全链路、组合拳、顶层设计、认知跃迁、生态位、效率革命、占据先发优势、抢占红利、彻底改变、大幅提升、核心竞争力、深度赋能、未来已来、开启新篇章、值得注意的是、需要指出的是、综上所述、从某种意义上说、在这个 XX 的时代。

**修法不是换个词，是把这句话想说的事直接说出来。**

- 「大幅提升效率」→「以前拆一个赛道要花一周，现在十几分钟」
- 「实现了成本的优化」→「Token 消耗降了 74%」
- 「赋能中小团队」→「一个五人小团队现在能干过去二十人的活」

### 6. 结尾检查

翻到最后三段，看有没有这几样：

- 时代意义总结 → 删。
- 全文摘要 → 删。
- 首尾呼应的漂亮句子 → 除非事物的含义真的变了，否则删。
- 「让我们一起拥抱 AI 时代」这类口号 → 删。

应当留下的是：一句大白话的判断 + 一句邀请。

> 每搞明白一件小事，就是给土壤松一锹土。
>
> 我们一起慢慢松。

### 7. 比喻检查

每个比喻问一句：本体和喻体里有没有一个是能上手摸到的东西？

- 快递代金券、砍刀、种地、银行、兜里的现金、快递单号、签字 → 留。
- 浪潮、底座、钥匙、抽屉、星辰大海、坍塌、温度 → 删。

抽象概念配抽象意象等于什么都没说。

### 8. 翻案句的密度和支撑

AYi 版允许翻案句，但要检查两件事：

- **密度**：全文超过 5 处 → 删到 2 到 4 处，保留最有材料支撑的。
- **支撑**：每个「不是 A 而是 B」后面，B 有没有材料。没有材料的翻案是空翻，改成正面陈述。

空翻的样子：「真正重要的不是工具，而是思维」——后面没有任何东西说明这个思维长什么样。

有支撑的样子：「真正的护城河不是参数」——后面用 52 天 74 个发布、PR 吞吐增长 67%、CLAUDE.md 的错误回写机制撑住了。

### 9. 排比检查

- 三项以内且是短口语句 → 留。
- 四项以上 → 砍到三项以内。
- 出现在总结段或抒情段 → 删，不管几项。

### 10. 感叹号

正文数一遍。每千字超过 1 个就删。标题不受这条限制。

### 11. 名词解释

找出所有专业名词，看第一次出现时有没有就地解释。

AYi 的解释方式是「这个词是啥，你可以这么理解……」加一个生活里的对照，不是维基百科定义。

> Token 是啥，你可以这么理解，AI 看东西、想东西、回答你，每一步都按字数收费，Token 就是它的算钱单位。

### 12. 免责与披露

涉及钱、健康、投资、法律、第三方产品，末尾必须有单独一段：

- 投资类：NFA / 不构成投资建议 / 可能损失全部本金
- 健康类：不构成诊疗或用药建议，具体请问医生
- 教程类：版本和文案以你当天看到的为准
- 商务类：本篇与 X 合作 / X 是我自用的工具，不构成推荐
- 整理类：数据以各官方页面为准，安装前点开链接核一眼

这一段用平白句子写，不修辞，不缩写，不藏在正文里。

## 常见跑偏的三种样子

### 样子一：写成了 3 月那批说明书

症状：句子长、无我、词很正式、每段都在下定义。

自查：把每段的「我」「你」删掉，读起来毫无损失。

修法：找出这篇里作者实际做过的动作，用这些动作重写开头和每一章的第一段。做不到就是材料不够，缩短篇幅或者问用户。

### 样子二：套路表演

症状：每个小标题都是翻案句，每三段一个「说实话」，比方一个接一个，泼冷水那段像走流程。

自查：把标志动作的出现次数数一遍。「说实话」全篇超过 3 次就多了（语料是每万字 3.5 次）。

修法：删掉一半，保留有材料的那一半。AYi 的口头禅是自然溢出的，不是按间隔撒的。

### 样子三：借了 AYi 的生平

症状：稿子里出现了用户没有的粉丝数、收益、经历、猫。

修法：全部换成用户自己的材料。用户没有对应经历时，把这一段改成「我查到」「有人做过」，或者直接删掉。

**文风可以套，经历不能套。** 这是这个 Skill 唯一不能破的规矩。

## 脚本

```bash
python3 ~/.claude/skills/human-writing-AYI/scripts/check_ayi.py 稿件路径
```

脚本能查的：段落长度分布、单句成段比例、人称密度、感叹号密度、机构腔硬禁词、模型腔路标、空转比喻、翻案句密度、排比项数、免责段缺失、数字锚点缺失。

脚本查不出来的：材料真假、比方土不土、泼冷水那段是不是走流程、翻案句有没有支撑。这四样只能自己读。

脚本报警不等于必须改。它给的是密度提示，最终判断在作者。硬禁词（机构腔那一批）除外，那些必须清零。
