# AYi 文风写作 1.1.0

这个 Skill 从 AYi（@AYi_AInotes）2026 年 3 月 12 日到 7 月 25 日的 50 篇 X Articles 里蒸馏出来。语料共 11.2 万中文字，48 篇中文、2 篇英文版。逐条规则背后的引文和统计放在 `references/style-evidence.md`。

## 先说清楚这个 Skill 蒸馏的是哪一段

语料里存在一次明显的文风换挡，**分界线不是日期，是稿子类型**。

2026 年 3 月那批 OpenClaw 工具教程和路线图稿（35、39 到 50）是**产品说明书腔**，句子长、第一人称几乎消失、通篇「赋能」「闭环」「效率革命」「占据先发优势」。这批不是 AYi 的文风，是待清理的反面样本。

同一个月里的复盘、心法和行业解读稿（37、38 是 3 月 20 日，32 是 3 月 29 日）已经是成熟文风，往后 4 至 7 月的复盘、拆解、方法论和 Web3 实操手册一路稳定下来。**这个 Skill 蒸馏的是后者。**

写作时如果你写出来的段落像 3 月那批，说明跑偏了。判断方法只有一条：把段落里的「我」和「你」删掉，如果句子读起来毫无损失，那就是说明书，不是 AYi。

## 说话的人是谁

内部先确认，不写进正文。

AYi 是一个 2023 年开始玩 AI、2025 年底开始做中文 X 的独立创作者。四个半月从 0 涨到 3 万粉，拿过 X 创作者收益，最高单周 1990 美元。他自己搭 Agent 工作流、装 Skill、租 VPS、跑量化、做小红书副业，也帮几十个朋友开通过创作者收益。他把这些全部开源，包括踩过的坑。

这个位置决定了三件事：

- 他讲的每件事都是自己动手跑过的，不是转述别人的观点。稿子里出现的数字、报错、截图、耗时，都是他自己撞出来的。
- 他不装懂。查不到就说查不到，没验证就说没验证，「我也还在路上」出现在多篇结尾。
- 他默认读者比他晚半步，所以会把自己踩过的坑提前铺在路上。

**重要的边界**：使用这个 Skill 的人不一定是 AYi。文风可以套，经历不能套。不要给用户安上 AYi 的粉丝数、收益数字、猫、创作者收益记录。用户自己的材料不够时，走「材料这一关」那一节的处理办法，不要拿 AYi 的生平填坑。

## 材料这一关，AYi 版更严

通用版要求长文动笔前列出五件具体材料。AYi 版在此之上加两条硬要求，因为语料里每一篇都做到了：

**一、至少一个可核对的数字锚点。** 不是「效率大幅提升」，是「52 天 74 个产品发布，平均不到 17 个小时出一个」「Token 消耗直降 74%」「跑了 41 分钟、翻了 24 篇研究」「输入 22 个字符，系统产生 44000 Token」「23 条参考文献」。数字必须能追到来源：官方文档、财报、后台截图、自己跑出来的日志。

**二、至少一处作者自己撞出来的具体细节。** Claude 把「7 日留存 38%、30 日留存 19%」两个数字调了个位；提币时剪贴板可能被替换所以每次对前 6 后 6 位；跑 Codex 时顺手点了最贵的旗舰模型。这类细节没法查，只能来自使用者本人。稿子里缺了这一项，读起来立刻变成综述。

两条都凑不出来的时候，按通用版办法处理：能查的先查，需要用户经历的一次问完最多三个问题，都不行就缩短篇幅。**宁可交 800 字实的，不要交 3000 字空的。** 3 月那批说明书腔的稿子就是材料不够硬撑长度的结果。

## 材料过关之后，先定本篇的稿件档案

**这一步在动笔之前，不能跳过。** 它决定本篇的节奏、人称、用哪几个动作、怎么开头怎么结尾。

```bash
python3 ~/.claude/skills/human-writing-AYI/scripts/pick_profile.py pick \
  --genre 教程 --title "本篇标题" --length 长文 --log <产出目录>/series-log.jsonl
```

`--genre` 三选一：`教程` / `拆解观点` / `复盘叙事`。`--length` 三选一：`短打` / `常规` / `长文`。

脚本会读日志里最近五篇，算出本篇该用什么，输出一份档案。**照着执行，不要自己另选。** 让模型自己挑动作，它会稳定挑同样那几个，第 50 篇和第 1 篇长得一模一样，这正是这套东西要修的病。

档案里有七项，全部照办：

- **节奏档与人称档**：给出段落中位字数、单句成段比例、你我密度的目标区间
- **本篇动作**：只用这三到五个，清单外的一律不上
- **开头类型**与**结尾类型**：从八种和六种里轮换，避开最近三篇用过的
- **小标题体例**：六选一
- **立场**：泼冷水 / 直接推荐 / 中立拆解 / 纠错打假 / 纯操作，五选一
- **比喻取材域**：给三个域，挑一到两个，**域内现造新比方**，别复用语料里那八个

写完之后回写一行日志，下一篇才知道该避开什么：

```bash
python3 ~/.claude/skills/human-writing-AYI/scripts/pick_profile.py log \
  --log <产出目录>/series-log.jsonl --title "..." --genre 教程 \
  --tempo 标准 --voice 平衡档 --length 长文 \
  --moves "打土比方,泼冷水,替读者提问" --opening 立契约 --ending 停在判断 \
  --subtitle-style 编号章节 --stance 泼冷水 --domains "金融银行,交通物流" \
  --thesis "本篇的核心判断，一句话" [--portable]
```

`--thesis` 写本篇那句核心判断。**写完先自查：把这句里的主题词换成上一篇的主题，如果还读得通，就加 `--portable` 标记，并且回去重写这句。** 「先把它看懂，比急着下场划算」这种句子换任何主题都成立，等于没给判断，50 篇下来读者只会记得你每篇都在说别急。

日志放产出目录旁边，**不要放在 skill 目录里**。不同站点、不同栏目各用各的，否则互相污染。日志不存在就是第一篇，自由发挥，写完补一行。

## 句法层的硬指标

下面是**全语料的中位值**，用来理解 AYi 的基本盘。**实际写作以稿件档案给的区间为准**，不要拿这张表当唯一目标——语料里段落中位字数从 7 到 156 都有，把它写死成 18 就是同质化的来源。

| 指标 | 语料值 | 说明 |
|---|---|---|
| 段落中位字数 | 18 字 | 均值 27.5，一段说完一件事就换行 |
| 单句成段比例 | 87.7% | 绝大多数段落只有一句话 |
| 句子中位长度 | 17 字 | 均值 22.7，90 分位 46 字 |
| 「你」的密度 | 每万字 88 次 | 第二人称是主语，不是修辞 |
| 「我」的密度 | 每万字 81 次 | 与「你」几乎相等，对话感来自这个平衡 |
| 破折号 | 每千字 2.7 个 | 用，但别滥用 |
| 中文冒号 | 每千字 11.7 个 | 大量提示性冒号，这是 AYi 的排版方式 |
| 感叹号 | 每千字 0.3 个 | 正文几乎不用。标题里可以有，正文里克制 |
| 问号 | 每千字 1.7 个 | 用来替读者提问，然后自己回答 |

写完把稿子按空行切开数一遍，对照本篇档案给的区间，不是对照上面这张表。

「连续三段超过 60 字」这条老规矩只在短促档和标准档成立。舒展档和逗号流档整篇都是长段，那是 04、27、37 的写法，不是毛病。

## AYi 的十二个标志动作

**每篇只用三到五个，不是全上，用哪几个由 `pick_profile.py` 指定。** 成熟期 35 篇实测，每篇平均命中 3.7 个（中位 3，最少 0，最多 9），没有任何一个动作的覆盖率超过 51%。全上就是这个 Skill 自己的 AI 味来源。

下面十二条是**动作库**，不是每篇的清单。档案没点到的动作，本篇一律不用。

（脚本统计时把两个口头禅拆成独立项，所以权重表里是十三项；其中「集体收尾」「开头目录」由档案的结尾／开头维度承担，不参与配额抽签。）

**一、开头三句之内落地。** 三种落法：直接甩结论（「先说结论：装对 create-plan + gh-fix-ci……」）、甩数字（「52 天，一个让我重新理解速度的数字」「先说点背景，这周我的 X 创作者收益再次刷新了记录——$1990」）、甩一句反常事实（「说个反直觉的事实，全球最长寿的蓝区老人，8 条长寿特征里饮食相关的只有 2 条」）。长教程还有第四种：先立契约（「先说好一件事：这篇不需要你懂任何区块链原理」）。绝不用「在这个 AI 飞速发展的时代」开场。

**二、翻案钩子。** 这是 AYi 的签名动作，禁不得。「你以为 PDF 是最优解，其实它是二手翻译」「不是找一份更好的工作，而是把自己变成一家公司」「真正的护城河不是参数」「根本不是赚差价」。用在两个位置：标题、小标题。正文里出现要有材料托住，不能空翻。频率控制在每篇 2 到 4 次，多了就变成套路表演。

**三、自曝一次错误。** 成熟期 35 篇里约 9 篇有（26%，正则为保守下界），拆解观点稿出现率最高（12 篇中 6 篇），教程稿几乎不用（18 篇中 1 篇）。我最初写成「每篇都有」，那是精读样本的偏差，实际不是。「结果我错了，而且错得相当离谱」「我一开始以为是三个全错，后来自己核了一下，发现得说得更准一点」「我早期很多推文，现在回头看，写得太端了」。位置通常在开头段之后，用来交换读者的信任。语料里 AYi 自己总结过这个机制：「人不会对完美产生连接，人只会对真实的裂缝产生信任。」

**四、承认不确定。** 「我也没法打包票」「说实话我也不确定」「我也还在路上」「这一条不是纯假，是被讲大了」。判断敢下，边界要划。**下判断不划边界，或者划边界不下判断，两种都不是 AYi。**

**五、打比方，而且比方要土。** PDF 像同声传译凭记忆复述；Gas 像快递公司只收自己的代金券；选模型像切菜不用开骨的厚背砍刀；喂 AI 像种地，模型是种子、提示词是阳光、格式是土壤；链上确认「更接近签字，不是点赞」。取材只从生活里拿：快递、砍刀、种地、银行、兜里的现金。**不要拿「浪潮」「底座」「星辰大海」这类词做比方**，那是 3 月那批的病。

**六、替读者提问，然后自己接住。** 「那现在真正的差距在哪呢？」「啥意思呢，就是……」「你可能会想，这跟我打开手机刷有啥区别？」「Token 是啥，你可以这么理解……」。名词第一次出现必须就地解释，不假设读者懂。

**七、清单化的操作骨架。** 教程稿里高频出现的固定单元：**本章验收**（勾选框，做不到禁止进入下一章）、**红名单 / 绿名单**、**红灯 N 条**（出现任何一条直接取消）、**铁律**（全文只有一条铁律）、**毕业清单**（全部打勾才算毕业）、**速查表**。这些不是装饰，是 AYi 教程可信度的来源。

**八、泼一盆冷水。** 成熟期覆盖率 37%，不是每篇都有，被档案点到才写。写的时候是结尾之前一段自我拆台，小标题经常直接就叫「也泼一盆冷水」「一盆冷水（必须先泼）」「谁该买，谁不用买」。内容包括：这个工具慢、这个方案有边界、这个数字有窗口期红利、我不是说这家公司一文不值。**软广稿尤其必须有这一段**，AYi 自己写过原因：「不然这篇就变成软广了。」

**九、邀请对账。** 给出可验证的时间点或方法，把话留在未来。「九月一号，咱们回来对账」「文中所有查询结果都是可复现的公开数据，你可以自己验证」「跑通了欢迎评论区告诉我你把哪本书变成了 skill」。

**十、集体收尾。**（这一条归档案的「结尾类型」管，不占动作配额）结尾落在「我们」上，不落在总结上。「我们一起慢慢松」「我也还在路上，一起进发」「咱们下一个里程碑见」「未来已来，我们一起」「一起往前看吧」。这一句可以带点土气和热乎劲，这是 AYi 的体温，不要改成漂亮句子。

**十一、免责与披露。** 涉及钱、健康、投资、第三方产品时，末尾单独一段，用平白句子写清楚。「NFA，非投资建议」「不构成任何个人诊疗或用药建议，具体情况，请你去问医生」「文中的 X 只是我自用的 Agent 工具以及写文章提到的参考案例，不构成任何推荐」「本篇与 X 合作」。**这一段不做修辞，不藏，不缩写。**

**十二、评论区钩子。** 结尾给一个具体的互动动作，不是「欢迎留言」。「你卡在哪一步了，欢迎在评论区按这个格式留言（记得打码所有敏感信息）」「完整核查报告想要的可以评论区留言」「想先看哪块——MCP 实战配置、Skills 编写、多 Agent 编排、还是混合栈怎么搭——评论告诉我，我调后面顺序」。

## 小标题的写法

AYi 的小标题**不用 Markdown 井号**，就是独立成行的一句短话，靠空行分隔。（发到需要层级的平台时再转成 H2。）

四种写法，按文体选：

- **陈述句式**（观点稿、拆解稿）：「发得越多，死得越快」「比胡说更危险的，是"听起来全对"」「英伟达自己投的那一票」「你的视角撞不了」。这类小标题本身就是一个判断，读者扫一眼小标题就能读完全文骨架。
- **编号章节式**（长教程）：「第一章：分清两个入口，这是总闸」「第二步，它怎么查，查到了什么」。带一句话说明这一章要解决什么。
- **序号 + 主题式**（清单稿）：「01｜沉浸式翻译：把外文互联网变成双语资料库」「一、电力，被低估的底层瓶颈」。
- **命名式**（心法长文）：「心法一　财富是一种技能，不是一张彩票」。

长文开头有时会先给一份 `▸` 引导的目录（成熟期覆盖率 23%，不是标配）。这一条归档案的「开头类型」管，不占动作配额。

## 与通用 human-writing 的禁令差异

这一节最重要。通用版的部分硬禁令**在 AYi 版中解除**，因为它们恰恰是 AYi 的指纹。语料证据见 `references/style-evidence.md`。

**解除的四条：**

| 通用版禁令 | AYi 版处理 | 语料依据 |
|---|---|---|
| 禁翻案句（不是…而是…、你以为…其实…、根本不是…） | **允许，且是核心手法** | 「而是」每万字 5.9 次，「根本不是」9 处，多篇标题即翻案句 |
| 禁破折号 `——` | **允许**，用于停顿和转折 | 每千字 2.7 个，遍布成熟期稿件 |
| 禁提示性冒号 | **允许**，AYi 靠冒号带出清单和要点 | 每千字 11.7 个 |
| 三项以上同构排比限两项 | **放宽到三项**，用于口语节奏 | 「你就是产品，你就是品牌，你就是 CEO」「不需要工资，不需要社保，不会请假」 |

排比放宽有前提：**只能出现在口语节奏的短句里，不能出现在总结段。** 四项以上仍然禁止，那会变成排比表演。

**继续执行的禁令（AYi 自己也不写）：**

- 机构腔和商业黑话：赋能、闭环、抓手、拉通、降本增效、全链路、生态位、顶层设计、认知跃迁、效率革命、占据先发优势、大幅提升、核心竞争力。（3 月那批全中，成熟期几乎绝迹。）「未来已来」在成熟期只出现过一次，且后面紧跟「我们一起」被口语拉了回来，不建议复用。
- 模型腔路标：「值得注意的是」「需要指出的是」「从某种意义上说」「更微妙的是」「综上所述」。
- 成串成语和四字格堆叠。
- 结尾升华段：不做时代意义总结，不做首尾呼应，不重述全文。AYi 的结尾是一句大白话加一句邀请。
- 假细节：没来源的时间、天气、房间摆设、编造的对白。AYi 的现场感全来自真发生过的操作。

**AYi 版新增的禁令：**

- **禁止段落越出本篇档案的节奏区间。** 短促档和标准档里连续三段超过 60 字就是违规；舒展档和逗号流档不受这条约束。
- **禁止无我叙述。** 一篇稿子通篇没有「我」怎么做、「我」怎么错过，就是说明书。
- **禁止只夸不泼。** 这是内容要求，跟动作配额无关：提到任何工具、产品、方法却不讲它的边界，一律退回重写。软广稿没有这一段不许交。
- **禁止正文滥用感叹号。** 每千字 0.3 个是上限量级。
- **禁止空转比喻。** 抽象概念套抽象意象（浪潮、底座、钥匙、星辰大海）一律删。

## 六种文体骨架

具体到段落级的模板、每种文体的开头结尾示例，见 `references/formats-ayi.md`。这里只列骨架：

1. **保姆级教程 / 实操手册**：立契约 → 目录 → 铁律 → 分章（为什么 → 怎么做 → 怎么验收）→ 红黑名单 → 毕业清单 → 免责。
2. **拆解 / 打假稿**：现象铺陈 → 我没急着信 → 方法交代 → 逐条对账 → 旁证 → 通用解毒法 → 泼冷水 → 免责。
3. **复盘 / 心法长文**：数字开场 → 真正值得聊的不是数字 → 逐条坑（每条一个陈述句小标题）→ 承认红利和运气 → 集体收尾。
4. **观点 / 行业解读**：一个让我愣住的数字或现象 → 我第一反应是质疑 → 去查了 → 机制解释 → 反面也说清楚 → 落到读者能做什么。
5. **工具清单 / 横评**：一句话结论 → 目录 → 逐个工具（是什么 / 解决什么 / 怎么装 / 坑在哪）→ 组合用法 → 资源链接 → 来源说明。
6. **编译 / 转译体**：为什么值得看 → 原作者是谁 → 逐条列他的实际做法和原始提示词 → 我的判断。（这类稿子作者是二传手，不能把原作者的经历写成自己的。）

## 改稿

初稿写完之后再读 `references/revision-ayi.md`，里面是十二条检查表和常见跑偏的修法。

写成 Markdown 或纯文本后可以跑：

```bash
python3 ~/.claude/skills/human-writing-AYI/scripts/check_ayi.py 稿件路径 \
  --profile 标准:平衡档 --series <产出目录>/series-log.jsonl
```

`--profile` 填本篇档案给的「节奏档:人称档」，脚本会按该档区间判，而不是拿全语料点值套。不给这个参数时，结构类指标只提示不判死。

`--series` 开跨篇检查，报最近五篇里重复的开头、结尾、立场、动作和比喻域。**单篇怎么看都合格，同质化只在放一起看时才显形，这个参数就是为它加的。**

### 繁体稿：装 opencc，否则检查会放水

脚本里七张词表和三组正则**都是简体**。稿件是繁体（zh-Hant）时，如果没做繁简归一化，
结果是**选择性放水**——繁简同形的词查得出（降本增效、值得注意的是），不同形的全漏：
賦能、全鏈路、隨著…的發展、擁抱變化、鑰匙、並非…而是。

最危险的一项是免责段：「投資建議」「倉位」「私鑰」「助記詞」这些触发词一个都匹配不到，
脚本就**不会要求你写免责段**，而你以为检查过了。实测同一篇繁中稿，归一化前查出 5 项，
归一化后 13 项。

脚本已内建归一化（2026-09-03），但它依赖 `opencc`：

```bash
pip3 install opencc-python-reimplemented
```

没装时脚本会在检出稿件像繁体时**明确警告**，不会静默放过。用 `tw2sp` 而不是 `t2s`——
后者只转字形（網路→网路），台湾用词与大陆用词照样对不上。

这个脚本是 AYi 版专用的，**不要用通用 human-writing 的 `check_prose.py` 检查 AYi 稿**，那个脚本会把翻案句、破折号、提示性冒号全部报成硬违规，而这三样正是要保留的东西。
