# 工作区

临时区，不是归档区。

| 目录 | 放什么 | 什么时候清 |
|---|---|---|
| `审核报告/` | 每次立项审核的输出，命名 `YYYY-MM-DD-<主关键词>-立项审核.md` | **不清**。三个月后你会忘记当初为什么判定两篇文章不冲突，报告是唯一的依据 |
| `待导入/` | 存量文章的原始文件（docx / md / 表格） | 走完 [SOP-3](../05-SOP/SOP-3-存量文章导入.md) 校验、文件移进 `03-文章/` 后清空 |
| `增益/<article_id>/` | 闸 1.5 信息增益的 gain.md | **不清** |
| `C3-取词/` | 台湾繁中取词与 SERP 记录卡（N512 / 权威墙 / 意图纯度） | **不清**。90 天后数据需重抓，但判定过程要留 |
| `导出/<article_id>/` | docx 导出、案例原始数据 `data/*.json` + `README.md` + `derived.txt`、制图脚本 | **不清**。D20 与内容复核都读它 |
| `质检/` | M8 质检报告（含对外部复核的逐条处置） | **不清** |
| `复盘/` | 跨篇的流程复盘 | **不清** |
| `归档来源/` | 已放弃路线与历史导入批次的留档 | **不清**，也不再读 |

草稿写在 `03-文章/<lang>/` 里，用 `status: drafting` 标记，不要放这里——放这里的东西不进索引，等于系统看不见。
